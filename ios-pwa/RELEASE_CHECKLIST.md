# iPhone 真机验收

当前状态：Windows HTTPS 服务和 Chromium 离线验收完成；以下项目等待实际 iPhone 安装并信任本机证书后验证。尚未标记这些项目通过。

## 准备

1. 本机方案：手机与 Windows 连接同一 Wi-Fi，在 Safari 打开 `http://192.168.1.3:18769/https-setup/`，安装描述文件并在证书信任设置中完全信任 `Wallet Local HTTPS CA`，再访问 `https://192.168.1.3:18770/`。如果改用其他 HTTPS 静态站点，将 `release/wallet-ios-pwa-1.2.0-3.zip` 解压后的内容上传并保留目录结构，站点根目录应直接包含 `index.html`。已经使用 HTTP 的用户先在原地址验证改名/删除/图表功能；这些功能不要求迁移到 HTTPS。
2. 使用一个固定访问地址。若已经在另一个地址记账，先在旧地址导出 JSON 完整备份，再在新地址导入。
3. 首次验收使用少量临时账目；已有真实账目时先导出完整备份。
